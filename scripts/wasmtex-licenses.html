Complete corresponding source — available offline

The complete corresponding source consists of the upstream source archive (154,968,364 bytes) together with the TexyPaper worker source patch. Both are available offline in this distribution.

SHA-256: e6a1f9b8ad84c7127368bb521217af381407fcc0d5c5518114345d55b470d637.

The unmodified archive contains engine source snapshots, toolchain and port sources, patches, glue, interface definitions, Docker/build scripts, format inputs, manifests and rebuild/relink instructions. The WebAssembly MakeIndex port is modified; its exact source is in this archive. Unrelated TexyPaper code is not part of this engine source unit.

The local modification permits safe relative package names only through TexyPaper's installed-tree provider, never a remote mirror, and encodes them into flat cache filenames. No WebAssembly or format bytes are changed. Extract the upstream archive, then run patch -p1 < /path/to/texypaper-wasmtex-2026-local-assets.patch from its root before following REBUILD.md. The patch targets source/wasmtex/a97db8a62ed86b118bcfcc8784b7752aa8e988ac/wasm-build/pdftex-worker.js. The installed manifest binds the original and modified worker digests to this patch.

Upstream source mirror. TexyPaper's release packaging supplies the verified archive and local source patch as companion release assets. Keep both available alongside every binary release.

TeX packages and fonts are read from the user's locally installed TeX Live distribution, not a cloud compiler. That separate distribution retains its own package notices, copying information and source materials; see TeX Live copying conditions.
