LICENSE TEXT SOURCES
====================

DEPENDENCIES.tsv records exact resolved versions and manifest license
expressions from the installed pnpm dependency tree and Cargo's locked
Windows x86_64-pc-windows-msvc normal/build dependency resolution. It lists
338 third-party Cargo packages including build tools and 35 installed npm
production-tree manifests. An entry does not assert that every package is
linked into the executable or emitted into JavaScript. Native Node canvas
binaries are optional PDF.js Node support, not browser assets to redistribute.
Development dependencies other than the explicitly attributed ssh2 example
are outside this inventory. Absent non-Windows optional npm packages are not
represented as installed or bundled.

licenses/rust/<crate>-<version> contains root LICENSE*/COPYING*/NOTICE* files
provided in the exact local Cargo source archives; no contributor names are
invented from package metadata. licenses/npm/<name>-<version> contains the
installed package's applicable root license notices. Scoped names use __ in
place of /. Line endings can be normalized to LF; notice text is retained.

Some Cargo archives omit their upstream root license. For those packages,
these license texts were retrieved from the upstream Git commit identified
by the archive's .cargo_vcs_info.json, not from an unpinned default branch:

plist 1.10.3 supplies LICENCE (British spelling), preserved as such.
selectors 0.38.0 declares MPL-2.0 but omits a full license file from its crate;
its LICENSE-MPL-2.0 here is the unmodified standard MPL 2.0 text supplied by
cssparser in the same resolved dependency closure, not an invented upstream
copyright notice. Exact selectors source is linked in DEPENDENCIES.tsv.

PDF.js asset license originals are from pdfjs-dist 6.5.438's LICENSE, cmaps/,
standard_fonts/ and wasm/ directories. Font and Microsoft loader provenance
and source/checksum details are in their respective ORIGIN.txt files.

This inventory preserves known dependency license material. It is not an
exhaustive legal audit of all source-level embedded notices, generated
code, compiler runtimes, installer tooling or later package changes.
Do not treat it as signed-off distribution authorization.
